سحابة المكتب الفني | Technical Office Cloud (TOC) - نسخة HTML مستقلة

1) افتح index.html لموقع العرض فقط.
2) افتح admin.html للوحة الإدارة.
3) اسم المدير: Ali Mohammed
4) رمز الدخول المؤقت: 1234
5) ارفع جميع الملفات معًا إلى مجلد public_html في الاستضافة.

إضافة ملفات المشروع:
- ادخل إلى admin.html ثم اختر تعديل المشروع.
- من خانة «إضافة ملفات المشروع» اختر Excel أو PDF أو Word أو DWG أو الصور.
- الحد الأقصى للملف الواحد في نسخة HTML هو 3 ميجابايت.
- الملفات تحفظ داخل متصفح الجهاز وتظهر في تفاصيل المشروع على نفس الجهاز.

مهم: هذه نسخة HTML ثابتة. التعديلات تحفظ في متصفح الجهاز نفسه باستخدام Local Storage. لكي تظهر التعديلات لكل الزوار وعلى جميع الأجهزة، يلزم ربطها بقاعدة بيانات واستضافة خلفية. حماية كلمة المرور داخل HTML حماية أولية وليست مناسبة للنشر العام دون خادم آمن.


تحديث التصدير:
من لوحة الإدارة اضغط «تصدير HTML محدث»، أدخل رقم الإصدار واسم آخر معدل، ثم أرسل ملف HTML الناتج. يحتوي الملف على آخر بيانات المشاريع ويعمل مستقلاً دون الحاجة إلى مجلد الموقع.


تحديث: تمت استعادة إعدادات خط V35 الأصلية (Noto Kufi Arabic) مع الإبقاء على إصلاح الدخول وتصدير HTML.

تم تثبيت الخط الأصلي داخل ملف HTML المُصدّر، لذلك لا تتغير الهوية البصرية بعد التصدير أو عند فتحه على جهاز آخر.

تحديث المقدمة — عرض صور المشاريع:
- تم الحفاظ على تصميم مقدمة V35 كما هو.
- تعرض صور المشاريع الموجودة في صفحة المشاريع بصورة تتابعية داخل خلفية المقدمة.
- مدة عرض كل صورة في مقدمة المنصة: 3.5 ثوانٍ، مع انتقال ناعم بين الصور.
- تعمل الميزة كذلك داخل نسخة HTML المحدثة التي يتم تصديرها من صفحة الإدارة.
- تم تحسين وضوح صور المشاريع في المقدمة مع الحفاظ على وضوح النصوص ومدة 3.5 ثوانٍ لكل صورة.
- تم تحسين بطاقات المشاريع: عند مرور الماوس تظهر الصورة بوضوح مع تدرج داكن ونص أبيض/ذهبي لسهولة القراءة.


تحديث: عند تمرير المؤشر فوق بطاقة أي مشروع تظهر صورة المشروع بوضوح 100% دون طبقة شفافية، مع بقاء العرض العادي كما هو.

- تمت إضافة معرض مشاريع متحرك في القسم السفلي (5 ثوانٍ لكل مشروع).
- تمت إضافة عبارة «إعداد المكتب الفني» في التذييل.


آخر تعديل: تم تحويل مؤشر إنجاز بطاقات المشاريع إلى حلقة SVG؛ الجزء الذهبي يساوي نسبة الإنجاز، والجزء المتبقي فاتح، ومركز الحلقة شفاف ليُظهر صورة المشروع. التعديل مضمن في تصدير HTML المحدث.


تحديث المؤشر: الحلقة الذهبية الآن مطابقة تمامًا لنسبة الإنجاز لكل مشروع من 0% إلى 100%، باستخدام SVG pathLength=100، مع مركز شفاف.

تحديث ترتيب الصفحة: معرض المشاريع ثم لوحة الأداء ثم سجل المشاريع.
- تم تغيير صورة البداية في عرض صور مقدمة المنصة لتبدأ من صورة مشروع مختلفة، مع ضبط مدة العرض إلى 3.5 ثوانٍ.

تحديث مركز المتابعة:
- تمت إضافة مركز التنبيهات والمواعيد بعد معرض المشاريع.
- يعرض المشاريع المتأخرة تلقائيًا بحسب تاريخ النهاية والحالة ونسبة الإنجاز.
- يعرض العقود التي يتبقى على انتهائها 30 يومًا أو أقل؛ أدخل «تاريخ انتهاء العقد» من لوحة الإدارة.
- تمت إضافة خانة «نواقص المشروع» في لوحة الإدارة، ويُكتب كل نقص في سطر مستقل.
- تظهر النواقص داخل بطاقة تفاصيل المشروع مع عدد البنود.
- تمت إضافة سجل تحديثات لكل مشروع يسجل تاريخ ووقت التعديل والبيانات القديمة والجديدة تلقائيًا.
- جميع هذه البيانات تُضمّن في ملف HTML المحدث عند التصدير.
- مدة صور المقدمة ومعرض المشاريع: 3 ثوانٍ لكل صورة.

تحديث التنبيهات: أضيفت المشاريع القريبة من تاريخ الانتهاء خلال 30 يومًا كقسم مستقل، مع استمرار عرض المشاريع المتأخرة والعقود القريبة من الانتهاء.

تحديث سجل التاريخ: تمت إضافة شريط واضح أسفل القائمة يعرض تاريخ ووقت آخر تعديل ونوعه، مع إظهار آخر تحديث داخل بطاقات المشاريع وتفاصيل كل مشروع. يتحدث الشريط عند إضافة أو تعديل أو حذف مشروع، وعند تحديث أرقام الشركة أو استعادة البيانات، ويُضمّن داخل ملف HTML المصدّر.

تحديث: تمت إضافة زر «إغلاق المنصة» مع أنميشن إغلاق ذهبي مدته 3 ثوانٍ، وشاشة بديلة إذا منع المتصفح الإغلاق التلقائي.
